**Можно ли в HashMap положить null-ключ или null-значение?**

В HashMap — да (один null-ключ хранится в bucket 0). В ConcurrentHashMap — нельзя ни ключ, ни значение.

**Почему NULL = NULL даёт UNKNOWN, а не TRUE?**

NULL — это «значение неизвестно». Два неизвестных значения — нельзя сказать, равны они или нет. Поэтому NULL = NULL это не TRUE, а UNKNOWN, в условиях ведёт себя как FALSE. Для проверки используется IS NULL.

**Что такое PRIMARY KEY и FOREIGN KEY?**

PRIMARY KEY — уникальный идентификатор строки. NOT NULL, UNIQUE автоматически. На таблицу может быть только один. FOREIGN KEY — ссылка на PRIMARY KEY (или UNIQUE) другой таблицы. Поддерживает целостность данных: нельзя добавить заказ с user_id, которого нет в таблице users.

**Может ли значение в столбце, на который наложено ограничение `FOREIGN KEY`, равняться `NULL`?**
Может, если на данный столбец не наложено ограничение `NOT NULL`.
