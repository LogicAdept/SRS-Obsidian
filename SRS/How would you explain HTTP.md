**Какие HTTP-методы знаешь?**

GET — получение данных, тело не предполагается. POST — создание, отправка данных в body. PUT — полное обновление / создание. PATCH — частичное обновление. DELETE — удаление. HEAD — как GET, но без body (только headers). OPTIONS — какие методы разрешены (CORS).
