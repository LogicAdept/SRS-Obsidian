**What is memory visibility?**

Источник: https://habr.com/ru/articles/966892/

Поток может работать с копиями в кэше ядра. Нет гарантии, что другой поток сразу увидит запись в обычную переменную: старое значение, задержка, другой порядок. Нужны synchronized, volatile или locks.
