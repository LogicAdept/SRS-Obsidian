**What is machine learning?**

Algorithms that learn patterns from data instead of hard-coded rules. Goal: generalize to unseen examples. Supervised / unsupervised / reinforcement. Interview: name a production loop (data → train → evaluate → deploy → monitor), not just 'AI'.
