> [!warning] Untrusted draft

The Network layer (Layer 3) handles logical addressing (typically IP) and routing packets between networks. It selects paths and is where routers primarily make forwarding decisions across different networks.

> - Switches that do IP routing are multilayer; classic exam answer for pure routing is still Layer 3.
