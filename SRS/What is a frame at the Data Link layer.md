A frame is the Data Link layer PDU. It encapsulates a network packet with link-layer addressing (for Ethernet: MAC addresses) and typically includes error-detection fields. Switches forward frames inside a LAN.
> [!warning] Unverified traps from the dump
> - Calling an IP packet a frame (or vice versa) is a frequent naming error in interviews.
