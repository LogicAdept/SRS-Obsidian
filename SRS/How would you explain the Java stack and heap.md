**What is stored on the JVM stack versus the heap?**

Источник: https://habr.com/ru/articles/967190/

Heap: экземпляры объектов и их поля. Ссылки на объекты обычно лежат в стеке или в полях других объектов на куче.
Stack: у каждого потока свой стек из фреймов. Во фрейме — локальные переменные (включая ссылки на heap), операндный стек, ссылка на constant pool класса. Когда метод завершается, фрейм удаляется.
