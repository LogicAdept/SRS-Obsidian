**What is AMQP?**

Advanced Message Queuing Protocol — open application-layer protocol for MOM. RabbitMQ's native model is AMQP 0-9-1 (exchanges, queues, bindings, channels). AMQP 1.0 is a different peer-to-peer protocol; RabbitMQ supports it as a plugin, not as the same routing model.
