**Какую сортировку использует Java по умолчанию?**

Для массивов примитивов — Dual-Pivot Quicksort. Для объектов — Timsort (гибрид merge и insertion sort, разработан для Python, перенесён в Java). Timsort стабилен и эффективен на реальных данных, где часто есть упорядоченные подпоследовательности.
