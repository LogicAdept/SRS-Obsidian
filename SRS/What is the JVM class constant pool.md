**What is the class constant pool?**

Источник: https://habr.com/ru/articles/967190/

Constant Pool — место в метаданных класса (Method Area), где хранятся константы, литералы и ссылки на методы/классы. Аналогия из статьи: шкаф с готовыми вещами, а stack — стол, на котором их раскладывают для работы.
