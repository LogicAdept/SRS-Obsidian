A duplicate IP address on the same subnet is a Layer 3 (Network) addressing problem in OSI troubleshooting scenarios. Two hosts sharing one logical address breaks IP uniqueness on that network.
> [!warning] Unverified traps from the dump
> - Symptoms may show up in ARP traffic at Layer 2, but the misconfiguration is logical addressing at Layer 3.
