**Какие scope у зависимостей в Maven?**

compile (default) — доступно везде, идёт в финальный jar. test — только для тестов. provided — для компиляции, но не в финальный jar (например, servlet-api — его даёт Tomcat). runtime — в рантайме, но не при компиляции (например, JDBC-драйвер). system — локальный jar, не использовать.
