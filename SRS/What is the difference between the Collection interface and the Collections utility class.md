**What is the difference between `java.util.Collection` and `java.util.Collections`?**

- `java.util.Collection` is a root **interface** of the Java Collections Framework (a group of elements).
- `java.util.Collections` is a **class** of static utility methods that operate on collections.
- Dump wording called both “classes.” `Collection` is not a class.
