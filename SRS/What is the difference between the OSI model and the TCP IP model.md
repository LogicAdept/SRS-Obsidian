#Networking/OSI #SRS #New

> [!warning] Untrusted draft
> Copied from an external question dump. Not checked against official documentation. Do not treat this as a review answer.

OSI is a seven-layer reference model. The TCP/IP (Internet) model is commonly taught as four layers: Application, Transport, Internet, and Network Interface (Link). Rough mapping: TCP/IP Application ≈ OSI Application + Presentation + Session; Transport ≈ Transport; Internet ≈ Network; Network Interface ≈ Data Link + Physical. TCP/IP describes the stack used on the Internet; OSI is the broader standards reference.
> [!warning] Unverified traps from the dump
> - Some materials show five TCP/IP layers by splitting Link into Data Link and Physical.
> - Layer names differ across textbooks (Network Interface vs Link vs Network Access).
