Dumps: `Hashtable` has been in Java since **version 1.0**. HashMap-vs-Hashtable tables call `Hashtable` a **legacy** class and say **`HashMap` was introduced in JDK 1.2**. `ConcurrentHashMap` is named as **Java 1.5** in the concurrent-map dump.

> [!warning] Unverified traps from the dump
> - Some tables only say “legacy” and pin the version number on `HashMap` (1.2), not on `Hashtable`.
> - Enumeration dumps also date Enumeration to JDK 1.0 and Iterator to JDK 1.2; that is the same split as `Hashtable` vs `HashMap` in those lists.
