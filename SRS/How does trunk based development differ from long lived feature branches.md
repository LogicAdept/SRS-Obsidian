**Что такое Git Flow и Trunk-based?**

Git Flow — модель с долгоживущими ветками master, develop, feature/*, release/*, hotfix/*. Подходит для релизного цикла с явными версиями. Trunk-based — все работают близко к master (через короткие feature-branch'ы), часто мерджат. Используется в командах с CI/CD и непрерывным деплоем.
