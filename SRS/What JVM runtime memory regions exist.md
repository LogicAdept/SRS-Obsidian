**Какие области памяти в JVM? Что хранится в heap, а что в stack?**

Heap — объекты и массивы; stack — фреймы методов, примитивы, ссылки.

**Из чего состоит память Java?**

Основные области: Heap (куча) — здесь живут все объекты. Stack (стек) — у каждого потока свой, хранит локальные переменные и фреймы вызовов. Metaspace (с Java 8 заменил PermGen) — метаданные классов, статические поля. Также есть Code Cache (для JIT-кода) и Direct Memory (off-heap).
