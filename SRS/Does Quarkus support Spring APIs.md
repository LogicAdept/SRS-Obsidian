# Does Quarkus support Spring APIs

> [!warning] Untrusted draft
> Drafted from general framework knowledge, not from an opened question dump. Not yet checked against official documentation. Do not treat this as a review answer.
Draft cue: compatibility extensions exist — quarkus-spring-di, spring-web, spring-data-jpa, spring-security, spring-cache, spring-boot-properties, spring-tx, spring-scheduled — they compile Spring annotations onto Quarkus equivalents at build time.
Not a full Spring runtime; no Spring context; coverage is partial and documented per guide.
