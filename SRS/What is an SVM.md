**What is a support vector machine?**

Max-margin classifier. Linear: hinge loss + L2. Kernel trick for nonlinear boundaries (RBF). Support vectors are the points that define the margin. Scale features. Slow on huge n compared with linear models / trees. Soft-margin C trades margin vs violations.
