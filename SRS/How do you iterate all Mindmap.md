**Как перебрать все ключи `Mindmap`?**

Использовать метод `keySet()`, который возвращает множество `Set<K>` ключей.

**Как перебрать все значения `Mindmap`?**

Использовать метод `values()`, который возвращает коллекцию `Collection<V>` значений.

**Как перебрать все пары «ключ-значение» в `Mindmap`?**

Использовать метод `entrySet()`, который возвращает множество `Set<Mindmap.Entry<K, V>` пар «ключ-значение».
