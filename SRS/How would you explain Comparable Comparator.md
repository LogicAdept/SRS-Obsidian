**В чём разница Comparable и Comparator?**

Comparable<T> — внутри класса (метод compareTo). Описывает «естественный» порядок. Один на класс. Comparator<T> — отдельно. Можно сделать несколько разных Comparator'ов для одного класса. Если нужно сортировать User по имени, по возрасту, по email — это три разных Comparator'а, а не три compareTo.
