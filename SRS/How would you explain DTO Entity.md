**В чём разница DTO и Entity?**

Entity — связана с БД (@Entity). Может иметь связи (LazyInitializationException наружу!). DTO — независимый объект для передачи. Хорошая практика: НЕ возвращать Entity из REST-контроллеров, маппить в DTO. Это разрывает зависимость API от схемы БД.
