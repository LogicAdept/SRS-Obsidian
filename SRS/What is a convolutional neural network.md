**What is a CNN?**

Shared convolutional filters + local receptive fields: translation-equivariant spatial features, far fewer params than a dense net on pixels. Pooling/strides for downsampling. Stacks build edges → parts → objects. Still used in vision; ViTs compete. Interview: parameter sharing and locality.
