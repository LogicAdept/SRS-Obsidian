**Linear vs logistic regression?**

Linear: predict continuous y, usually MSE. Logistic: binary (or softmax multiclass) probability via sigmoid, log-loss / cross-entropy. Both are linear in features unless you engineer them. Regularize; scale features; logistic is a classifier not 'regression' in the ML-task sense.
