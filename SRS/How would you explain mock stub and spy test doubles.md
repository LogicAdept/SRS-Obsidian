**В чём разница Mock и Spy?**

Mock — полная имитация, по умолчанию все методы возвращают null / 0 / false. Поведение задаёшь через when().thenReturn(). Spy — обёртка над реальным объектом. Методы, которые ты не подменил, работают как обычно. Полезно, когда хочется подменить ОДИН метод реального класса, не переписывая весь.
