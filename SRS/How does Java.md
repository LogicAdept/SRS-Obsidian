**Как работает чтение файлов в Java?**

Через потоки I/O: InputStream / OutputStream — для байтов. Reader / Writer — для символов (с учётом кодировки). Buffered-обёртки (BufferedReader, BufferedInputStream) — для эффективности, читают сразу пачку, потом отдают по запросу. Использовать обязательно в try-with-resources, чтобы закрыть.
