**Saga.**

Распределённые транзакции через цепочку локальных + компенсирующие действия. Choreography (события, децентрализованно) vs Orchestration (центральный оркестратор). Пример: оплата → списание → бронирование. Бронирование упало → возврат → отмена.

**Распределённые транзакции: 2PC vs Saga.**

2PC — координатор + участники, блокировки, плохо масштабируется. Saga — цепочка локальных транзакций с компенсирующими действиями. Хореография vs оркестрация.

**Saga-паттерн.**

Распределённые транзакции через цепочку локальных + компенсации. Choreography vs Orchestration.
