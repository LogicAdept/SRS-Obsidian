**MySQL to Postgres gotchas?**

Types (text vs tinyint boolean), quoting, IFNULL vs COALESCE, AUTO_INCREMENT vs IDENTITY, sql_mode vs strict Postgres, GROUP BY strictness, UPSERT syntax, JSON vs JSONB, vacuum instead of undo.
