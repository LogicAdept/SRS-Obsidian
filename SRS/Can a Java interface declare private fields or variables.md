**Что такое var (Java 10+)?**

Ключевое слово для вывода типа локальной переменной. var list = new ArrayList<String>(); — компилятор сам определит, что это ArrayList<String>. Использовать только для локальных переменных, не для полей и параметров. И только когда тип очевиден из контекста (var x = 5 — плохо, var users = repo.findAll() — норм).
