**Escape analysis — что это даёт?**

JIT определяет, «сбегает» ли объект из метода. Если нет — может аллоцировать на стеке вместо heap (scalar replacement).

**What is escape analysis?**

Источник: https://habr.com/ru/articles/967190/

Escape Analysis анализирует, покидает ли объект метод/поток. Если нет — объект может быть размещён в стеке вместо кучи, что снижает нагрузку на GC.
