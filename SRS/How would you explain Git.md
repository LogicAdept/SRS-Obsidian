**Какие команды Git знаешь?**

git clone — скачать репозиторий. git pull — забрать изменения. git push — отправить. git add — добавить файлы в staging. git commit — закоммитить. git branch — создать / посмотреть ветки. git checkout — переключить ветку. git merge — слить ветку. git rebase — переписать историю поверх другой ветки. git stash — отложить незакоммиченные изменения. git status / git log / git diff — состояние.
